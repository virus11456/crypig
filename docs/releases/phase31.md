# 第三十一批：全站閱讀排版整理

2026-09-15。基準版本 3db3e81ae6aeaa08fed9d5ae4f8d1a2a680094cf。

使用者截圖指出現貨地址表格沒有欄距，數字與單位緊黏。前次僅以無溢出判定排版通過不足，本批補上視覺閱讀檢查。

現貨地址區改為「餘額重點 → 分組比較 → 每日圖表 → 來源限制」。桌面表格加欄距、右對齊、等寬數字、合計列与正負色；900px 以下改分組卡片，缺值与零保持不同。圖表分成獨立區，刪除重複標題，限制说明可展開。

全站統一面板間距、數據卡、帳號表格、新聞列、策略區塊的字級和留白。圖表保留最小可讀寬度，在元件內滑動，不縮成小字。策略內層表格曾發現百分比被拆成兩行，改為完整欄寬与內部滑動，加入深色捲軸。所有原有市場資料与功能保留。

範圍：首頁 12 個主要面板（現貨地址、合約大額、聰明錢、LTH、同帳號明細、宏觀、DeFi、穩定幣、分歧、雷達、部位比較、幣別表）；策略頁 7 個面板（訊號驗證、新聞、Reddit、社群、回測、Obsidian、問答），另展開 7 個策略內層數字表。320／390／768／1024／1440px 五種寬度檢查，主要面板未檢出內容溢出。實際目視桌面比較表、手機分組卡、市場數據卡、手機策略數字表；不以無溢出代替目視。首次預覽缺回測／社群／訊號驗證資料，補抓正式站公開回應後重新檢查，沒有以空畫面計為完成。

44 項前端測試通過，包含手機／桌面資料一致、缺值、真零及文字 escaping；Vercel 匯出与 diff 檢查通過。無後端變更，本批未重跑 Python 全套。Chrome 尺寸模擬非實機 Safari；預覽混用既有回應与本次公开回應，不代表即時資料。正式部署狀態以 outputs 本批上線紀錄為準。
